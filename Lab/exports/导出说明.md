# 导出 Lab 提交包

`export_lab.py` 只使用 Python 3.10+ 标准库，无需安装额外依赖。脚本、本说明和[作业上交规范](作业上交规范.md)均位于 `Lab/exports`，生成的提交包也默认保存在此目录。

## 使用

在项目根目录运行：

```powershell
python .\Lab\exports\export_lab.py week1
```

也可以使用项目现有的 Python 环境：

```powershell
.\.venv\Scripts\python.exe .\Lab\exports\export_lab.py week1
```

在 `Lab` 目录内运行时，使用 `python .\exports\export_lab.py week1`；在 `Lab/exports` 目录内运行时，使用 `python .\export_lab.py week1`。参数既可以是 `week1`，也可以是 Lab 的完整路径。

脚本从报告文件名识别学号、姓名和周次。第 x 周的文件夹用 `weekx`，报告用 `学号-姓名-week_x.pdf`，周次不补零。例如：

```text
Lab/
└── week1/
    ├── src/
    │   └── circle.py
    ├── run.bat
    ├── requirements.txt
    └── docs/
        ├── 3220103613-王昊-week_1.md
        ├── pdf/
        │   ├── 3220103613-王昊-week_1.pdf
        │   └── 计算机图形学主要研究内容及应用.pdf
        └── images/
            └── circle.png
```

报告 PDF 必须提前生成；脚本不会把 Markdown 转成 PDF，也不会运行实验代码。

## 输出结构

默认生成 `Lab/exports/3220103613-王昊-week_1-week1-提交.zip`：

```text
3220103613-王昊-week_1-week1-提交.zip
├── 3220103613-王昊-week_1-week1.pdf
├── pdf/
│   └── 计算机图形学主要研究内容及应用.pdf
├── 3220103613-王昊-week_1-week1.zip
│   ├── src/
│   │   └── circle.py
│   ├── run.bat
│   └── requirements.txt
└── 实验结果/
    └── images/
        └── circle.png
```

规范中的 `xxx` 默认使用文件夹名 `week1`，也可以用 `--title` 指定实验名称：

```powershell
python .\Lab\exports\export_lab.py week1 --title "圆与Koch曲线"
```

此时主报告和代码 ZIP 分别叫 `3220103613-王昊-week_1-圆与Koch曲线.pdf` 和 `3220103613-王昊-week_1-圆与Koch曲线.zip`，总包加 `-提交` 后缀，其他 PDF 名称不变。

- PDF：`docs/pdf` 下的所有 PDF 都会打包（递归包含子目录，扩展名不区分大小写）。自动识别当前周次、文件名含学号和姓名的主报告，在总包根目录按提交格式命名；其余 PDF 放在总包的 `pdf` 目录内，保留原文件名和相对目录，避免同名文件冲突。链接文件和链接目录不跟随。
- 无法唯一确定主报告时，可用 `--report` 指定。该参数仅决定从哪个报告识别学号、姓名及重命名，不会排除其他 PDF。
- 代码 ZIP：保留 `src` 中支持的代码文件和 Lab 根目录的代码、启动脚本、依赖声明。包含 Python、C/C++、Java、JS/TS、着色器等常见代码类型；完整扩展名和构建文件名单见脚本的 `CODE_EXTENSIONS`、`BUILD_FILES`。
- 代码包排除文档、图片、视频、压缩包、编译产物、虚拟环境、缓存、隐藏目录和链接。`src` 下不支持的文件会在清单中列出；如有其他语言，可扩展 `CODE_EXTENSIONS`。
- 结果文件：收集 `docs` 下（除 `pdf` 目录）的常见图片、视频，包括 `docs/images` 和自行添加的 `docs/videos`，在 `实验结果` 内保留相对目录，避免同名文件冲突。
- 代码 ZIP 必须严格小于 **10,000,000 字节**，否则导出失败；此限制针对内部代码 ZIP，总包可以因 PDF、视频而更大。
- 缺少报告、源码或结果文件时会报错。已有同名总包默认不会覆盖，需加 `--force`。脚本不会修改 Lab 原文件。

## 其他参数

```powershell
# 预览选中的文件，不生成压缩包（不检查实际压缩大小）
python .\Lab\exports\export_lab.py week1 --dry-run

# 指定主报告；路径相对于 week1 文件夹，也支持完整路径，其他 PDF 仍全部打包
python .\Lab\exports\export_lab.py week1 --report "docs/pdf/3220103613-王昊-week_1.pdf"

# 报告使用其他文件名时，手动提供学号和姓名
python .\Lab\exports\export_lab.py week1 --report "docs/pdf/报告.pdf" --student-id 3220103613 --name 王昊

# 指定输出目录并允许覆盖同名总包
python .\Lab\exports\export_lab.py week1 --output-dir .\Lab\exports --force

# 查看所有参数
python .\Lab\exports\export_lab.py --help
```
